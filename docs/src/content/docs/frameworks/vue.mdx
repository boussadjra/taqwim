Two packages: `@taqwim/vue` for behaviour and accessibility with no styles, and
`@taqwim/vue-styled` for a calendar that already looks like one.

Both are thin bindings to [`@taqwim/calendar-core`](/reference/options/).
The state machine does the work; this package translates it into Vue.

## Common ground

Whatever the framework, the rendered DOM is the same. See
[Data attributes](/reference/attributes/) for the contract, and
[Theming](/guide/theming/) for how one stylesheet covers all five.

The option names are the same too — see
[Calendar options](/reference/options/). The `calendarSystem` option selects
[Umm al-Qura, Islamic Civil or Islamic TBLA](/guide/calendar-systems/).
Porting an example between frameworks is a matter of syntax, not of behaviour.
