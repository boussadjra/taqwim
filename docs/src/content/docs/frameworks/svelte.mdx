Two packages: `@taqwim/svelte` for behaviour and accessibility with no styles, and
`@taqwim/svelte-styled` for a calendar that already looks like one.

Both are thin bindings to [`@taqwim/calendar-core`](/reference/options/).
The state machine does the work; this package translates it into Svelte.

## Common ground

Whatever the framework, the rendered DOM is the same. See
[Data attributes](/reference/attributes/) for the contract, and
[Theming](/guide/theming/) for how one stylesheet covers all five.

The option names are the same too — see
[Calendar options](/reference/options/). Porting an example between
frameworks is a matter of syntax, not of behaviour.
