# Changelog

Per-package changelogs are generated by [Changesets](https://github.com/changesets/changesets) and live beside each package — `packages/*/CHANGELOG.md`. They are written when a release is versioned, so they do not exist yet.

## 0.1.0-beta.8 — unreleased

- Reject invalid and fractional date fields consistently across conversion APIs, and preserve Gregorian years 0–99.
- Reject non-finite business-day amounts instead of entering an unbounded loop.
- Preserve keyboard access after paging and changes to date availability, including calendars displaying several months.
- Allow selection in every displayed month when adjacent days are disabled, handle tabular navigation across year zero, and keep multi-month views within the Umm al-Qura table.
- Apply picker constraints to typed dates, handle out-of-range Gregorian input without throwing, and avoid formatting crashes when a strategy change invalidates a controlled selection.
- Give each Vue date picker a distinct popup ID.

## The pre-1.0 release line

Beta packages use the `beta` dist-tag. Per-package changelogs will be generated for the stable release; pending entries are in [`.changeset/`](./.changeset), each written for someone upgrading.

The headline changes since the pre-scope `taqwim-core-utils` / `taqwim-vue` packages, which are frozen in [`legacy/`](./legacy):

- **The `@taqwim` scope, thirteen packages in lockstep.** `taqwim-core-utils` became `@taqwim/core`; `taqwim-vue` split into `@taqwim/vue` (headless) and `@taqwim/vue-styled` (themed).
- **`@taqwim/calendar-core`** — calendar behaviour extracted into one framework-free state machine. Building it fixed props the Vue implementation advertised but ignored: `weekStartsOn`, `fixedWeeks`, `numberOfMonths` and `initialFocus` had no effect, `minValue`/`maxValue` gated only the paging buttons while leaving out-of-range days selectable, and there was no keyboard navigation at all.
- **React, Svelte 5, Solid and Angular adapters**, headless and themed, all binding to that same store.
- **`@taqwim/themes`** — themes selected with `data-taqwim-theme` instead of by importing a different stylesheet, so a page can host several and switch at runtime. Each theme is ~30 token overrides rather than a duplicated copy of every structural rule.
- **Corrected date math.** Business days now default to a Friday/Saturday weekend rather than the Monday–Friday week inherited from `date-fns`. Out-of-range dates throw `HijriRangeError` instead of returning silently wrong values.
- **Accessibility fixes** found by the shared Playwright suite: a roving tabindex that actually lets a keyboard user enter the grid, `aria-selected` removed from `role="button"`, and colour-contrast failures corrected in the bundled themes.
- **Docs** moved from VitePress to Astro Starlight, so live examples in five frameworks can share one page.

For migration instructions, see the [migration guide](https://boussadjra.github.io/taqwim/guide/migration/).

## Before the scope

`taqwim-core-utils@0.2.0` and `taqwim-vue@0.1.0` remain on npm at those versions and are not maintained. Their sources are kept in [`legacy/`](./legacy) for reference.
